# University Management System

A desktop application for managing university operations including student records, courses, grades, attendance, and more.

## About

This project was built as a university management solution with two implementations:
- **Desktop GUI** - C# WinForms application with SQLite database
- **CLI Version** - C++ console application

## Features

- Student registration and profile management
- Course enrollment and scheduling
- Grade tracking and GPA calculation
- Attendance management
- Faculty and department management
- Admin panel for system configuration
- Professor dashboard
- Payment tracking

## Tech Stack

- C# (.NET WinForms)
- C++ (CLI version)
- SQLite Database

## How to Run

### WinForms Application
1. Open `UniversitySystem.sln` in Visual Studio
2. Build and run the project

### CLI Version
1. Navigate to `cpp_sis-1 - Copy/cpp_sis`
2. Run `build.bat` or compile manually with g++
3. Execute `SIS_CLI.exe`

## Database

The project uses SQLite. Schema file is included in `schema.sql`.
